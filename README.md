

### **1. PROJECT INTRODUCTION**

- **Overview**: *This project is designed to assist high school students, particularly 12th graders preparing for their university entrance exams, in making informed decisions about their future academic paths. By using AI to analyze students' hobbies, strengths, and preferences, the platform helps guide them toward selecting the most suitable university majors. The goal is to empower students to make proactive and confident choices about their education and future careers, ensuring that they pick a major that aligns with their passions and advantages.*

- **Tech**: *JS, React, Flask*

### **3. USER GUIDANCE**

*This project uses Vite + React for Frontend and Flask Python for Backend.*

#### **STEP TO RUN THIS PROJECT**: 

- **Clone** the default branch *BE* to your computer.

- Then **open a terminal** in your IDE and enter the command:
 1. **RUN FRONTEND:**
-  If there is an error missing `package.json`, run the command:  	`npm install`
- and then run:  `npm run dev`
 2. **RUN BACKEND**
  again.
- **Next**, open another terminal in the IDE and run: `python backend.py`
 3. **ACCESS TO WEB TO MAKE A TEST**
- Finally, in the **Frontend terminal**, click the link to open the Frontend with `localhost` and test it.
